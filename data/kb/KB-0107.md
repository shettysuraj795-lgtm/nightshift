# Network timeout calling plant MES

## Symptoms

A sync job between SAP and the plant MES fails with a connection or read timeout.

## Log signatures

- `Connection to MES endpoint \S+ timed out`
- `Read timed out after \d+ ms`

## Background

Order and confirmation sync jobs call the MES interface of each plant. Short network interruptions or an MES restart during the sync window cause timeouts. The sync sends the full change set again on the next run, so a retry does not duplicate data.

## Resolution

1. Check the MES endpoint status for the plant
2. Rerun the sync job, which is idempotent, so a retry is safe
3. Escalate to plant IT if three consecutive runs time out

## Risk and approval

- Risk: low
- Approval required before a rerun: no
- Escalate to: L1
- Never do: `disable_tls_verification`

## Notes

If timeouts persist, plant IT should check the MES application server and the site network link. Never disable certificate verification to work around connection problems.

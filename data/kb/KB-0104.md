# Batch user missing an SAP authorisation

## Symptoms

A batch job cancels at the start of a step with an authorisation failure for its technical batch user.

## Log signatures

- `User BATCH_\w+ has no authorization for object`
- `Authority check failed for object`

## Background

Batch users hold roles that grant only the authorisation objects their jobs need. When a role is changed, for example during a quarterly access review, an object a job relies on can be removed by mistake. The job log names the object that failed the check.

## Resolution

1. Identify the missing authorisation object from the job log
2. Raise an access request with the SAP security team
3. Rerun the job once the role change is confirmed

## Risk and approval

- Risk: medium
- Approval required before a rerun: no
- Escalate to: L2
- Never do: `assign_sap_all`

## Notes

Never assign broad profiles such as SAP_ALL to a batch user to get a job running. Access changes always go through the SAP security team.

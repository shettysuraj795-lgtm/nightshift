# Supplier file missing on SFTP inbound folder

## Symptoms

The supplier import job ends without loading any data because the expected file is not in the supplier's inbound folder on the SFTP gateway.

## Log signatures

- `File .* not found in /inbound/`
- `SFTP: no matching file for pattern`

## Background

Suppliers upload advance shipping notices and price lists to their own inbound folder each evening. The import job polls the folder a few times and then cancels if no file matches the expected name pattern. The usual causes are a late upload, a file name that does not match the pattern, or an upload to the wrong folder.

## Resolution

1. Check the supplier's inbound folder for a late or misnamed file
2. Contact the supplier to resend the file
3. Rerun the import job once the file has arrived

## Risk and approval

- Risk: low
- Approval required before a rerun: no
- Escalate to: L1
- Never do: `create_placeholder_file`

## Notes

Do not create an empty or placeholder file to let the job finish: goods receiving would then work without the shipping notices. A rerun is safe once the real file is in place.
